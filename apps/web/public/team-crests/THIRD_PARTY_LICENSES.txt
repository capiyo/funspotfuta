# Football Logos Repository

A free, public repository containing **4.700+ football team logos** in SVG format, organized by country.

## Usage

Browse by country folder to find the team logo you need. Each folder contains SVG files named after the club.

### England

![England](https://raw.githubusercontent.com/JoseArroyave/football-logos/refs/heads/main/images/england.png)

### Italy

![Italy](https://raw.githubusercontent.com/JoseArroyave/football-logos/refs/heads/main/images/italy.png)

### Spain

![Spain](https://raw.githubusercontent.com/JoseArroyave/football-logos/refs/heads/main/images/spain.png)

### Germany

![Germany](https://raw.githubusercontent.com/JoseArroyave/football-logos/refs/heads/main/images/germany.png)

### Example

To find the Arsenal logo:

```
/logos/england/Arsenal.svg
```

## Direct Usage

You can use logos directly from GitHub using the raw URL format:

```
https://raw.githubusercontent.com/JoseArroyave/football-logos/refs/heads/main/logos/{country}/{logo_filename}
```

### Example

```html
<img src="https://raw.githubusercontent.com/JoseArroyave/football-logos/refs/heads/main/logos/england/Leicester.svg" alt="Leicester Logo" />
```

Output:

![Leicester](https://raw.githubusercontent.com/JoseArroyave/football-logos/refs/heads/main/logos/england/Leicester.svg)
